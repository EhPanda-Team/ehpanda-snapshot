# AGENTS.md

This file gives coding agents a reliable working guide for this repository.
Every agent, in any runtime, also reads the local [AGENTS.local.md](AGENTS.local.md) when it exists, before working on this project, and follows it.

## Working in this repository

- The pictures come only from `Scripts/visual/snapshot_publish.py` in the EhPanda repository, which assembles an
  owner-approved candidate run. Never add, edit, rename or delete a picture by hand: the app repository pins every
  picture's SHA-256, and any change here makes the screenshot check fail.
- Every push needs the owner's go-ahead for that push, and a new baseline needs the owner's approval of the whole
  set first.
